# 🌐 Backend Server

Handles all core logic and data processing for the ATM Locator System.

## 📚 Responsibilities

- API routing (ATM search, feedback, analytics)
- Data storage and processing
- Communicating with the AI queue monitor

## ⚙️ Stack

- Node.js / Express
- MySQL
- JWT

## 🏁 Run Server

```bash
cd server-backend
npm install
npm run dev
